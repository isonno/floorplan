You are an expert at creating interactive graphical web applications in JavaScript, and know how to write a Python script to act as a local web server to run the application on a local PC.

The application is a tool to help very basic design of residential floor plans. No details such as windows and doors are represented, it is only for deciding how to allocate space.

The application consists of a python script, `floorplan.py`. This creates a local HTTPServer, and then uses `webbrowser.open` to open a web browser and send the interactive web page (stored in `floorplan.html`). This web server also collects the data generated by the web app page, and allows data to be selected and loaded from the local file system into the web page app. All files for this application should be created in the directory /Users/jpeterso/floorplan/. All file handling should be capable of working on either Mac or Windows platforms.

A mock-up layout of the HTML web app is shown in the attached PNG file. While the dimensions specified in the mock-up are only roughly approximate, they give a good representation for what the app should look like.

On the left side, are a column of controls (buttons, checkboxes and a slider) on a white background for controlling the application. It's about 575 pixels wide. Everything to the right of this column is for editing the application's content.

The content area, on the right, displays a loaded background image (if specified). This background image is composited over a white background with 25% opacity, so it appears faded. An optional grid is displayed in faint, thin, light blue lines. This are set up with the Scale function (described below) so each grid square corresponds to a 1 foot x 1 foot box. If the image is zoomed in past 150%, then additional grid lines are displayed between the original grid lines corresponding to 0.5 foot intervals between the 1 foot intervals. These 0.5 foot lines are displayed with thin faint blue dotted lines. In terms of Z-order, the background is displayed, then the grid is displayed, then the spaces (described below) are displayed.

When a new "space" (i.e., a room) is created, it is displayed with a rounded rectangle. Each new space is displayed with it's name and the number of square feet of area it occupies. The edges of a space always snap to 0.5 foot intervals.

When the New Space button (described below) is clicked, a prompt appears asking for the name of the new space. After accepting the name, the cursor changes to a cross, and the space is defined by clicking and dragging. The opposite corners of the click and drag define the coordinates of the new space. The new space boundaries always snap to the nearest 0.5' interval. Once the space is created, the cursor reverts back to an arrow.

The name of the space and it's area (in square feet) are displayed in the center of the space, as shown in the mock-up.

Each new space is automatically given a bright, new, distinct primary color. (red, green, blue, yellow, cyan, magenta, violet, etc). The exception with the color is if the name of the space has a "." in it. Then, it will have a darker version of any related space. So for example, if a space has a name like "MasterBR", and is assigned a bright green color, "MasterBR.bath" will have a dark green color, and "MasterBR.closet" will also have a dark green color.

To edit a space, you may click and drag on either a corner or near the center of the side of a space. If the side of a space is clicked and dragged, the side moves with the cursor and the area changes (increasing or decreasing) as the edge is moved.

If you click on the corner of a space, then the area is conserved, so it remains the same. Thus if you move the cursor away from the center vertically, the wall of the space moves toward the center to preserve the area of the space.

While clicking and dragging a corner or edge of a space, the dimensions (width x height) in feet are displayed near the cursor.

If you click and drag on the center of a space. the space is moved without changing shape dimensions.

The controls on the left are as follows:
  * Load Background button. When clicked this pops up a dialog, allowing you to enter the pathname for a background image file. This file is displayed at 25% opacity over a white background in the content area. This allows an existing floorplan or site plan to serve as a guide for the new design.

  * Save Project button. When clicked this pops up a dialog to enter a pathname for the project in. The project is stored as a JSON file, and stores the following data:
    * The coordinates, dimensions, name and color of each "space" (room) (as described below)
    * The path to any loaded background file.
    * The last Scale setting (described below) as well as the position of the visible portion of the overall workspace.

  * Load Project button. When clicked this reads a JSON file with the above saved information, and sets up the background, scale, and display position, as well as all of the spaces (rooms) saved.

  * Set Scale button. This prompts for a measurement (say "16"). After the measurement is given, the cursor changes to a cross-hair. You click on one point and drag to another to determine the scale of the canvas. As you drag a line appears between the first click and to the point you're dragging, this line is constrained to be either horizontal or vertical. For example, if the background image has a room that is 16 feet wide, then when Set Scale is clicked, you enter "16" for the scale, then click on the left edge of the room and drag the cursor to the right edge. When the grid is drawn, there will be 16 one-foot grid squares drawn between the left and right edges of this room, setting the scale for all future drawing.

  * New Space button. See the above description - it changes the cursor to a cross-hair, and allows you to click and drag on the canvas to create a new shape.

  * Grid checkbox. If checked, the light blue grid is displayed, other wise it is not. Checked by default.

  * Background checkbox. If checked, the background is displayed, otherwise by default it is not. This is grayed out (disabled) if no background is specified.

  * Zoom slider. This allows you to change the scale of the canvas display. It ranges from 50% to 200%. The current percentage is displayed underneath it. The background, grid lines, and spaces are all equally transformed by the Zoom scale.

  If the entire drawing cannot be displayed on the canvas, scroll bars appear across the bottom and the right edge to allow the canvas to be re-positioned within the canvas view.
